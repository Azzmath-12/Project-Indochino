# Indochino Clone - Men's Custom Apparel Landing Page

A responsive e-commerce frontend landing page inspired by Indochino, built with HTML5, custom CSS, and Font Awesome[cite: 2]. The design showcases made-to-measure suits, custom menswear collections, seasonal banners, and customer measurement guides[cite: 2].

---

## 🚀 Live Demo

[View Live Project](https://azzmath-12.github.io/Project-Indochino/)

---

## 📌 Key Features

- **Hero Banner**: Engaging header section featuring full-bleed banner graphics and call-to-action buttons[cite: 2].
- **Product Showcase**: Grid layouts displaying tailored suits, blazers, and custom apparel collections[cite: 2].
- **How It Works / Measuring Process**: Step-by-step visual cards explaining the custom-tailoring workflow.
- **Responsive Navigation**: Header menu with dropdowns and category links for smooth user navigation[cite: 2].
- **Font Awesome Integration**: Vector icons for search, shopping cart, user accounts, and navigational cues[cite: 2].
- **Cross-Device Compatibility**: Styled for desktops, tablets, and mobile screens.

---

## 🛠️ Tech Stack

- **HTML5**: Semantic web architecture and page layout[cite: 2].
- **CSS3**: Custom layouts, Flexbox/Grid systems, media queries, and color schemes[cite: 2].
- **Font Awesome**: UI icons and iconography assets[cite: 2].
